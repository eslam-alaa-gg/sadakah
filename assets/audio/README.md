# إدارة ملفات الصوت

```text
assets/audio/
├── README.md                  ← هذا الملف
└── quran/
    ├── metadata.json          ← بيانات الصوت (الاسم، القارئ، المسار)
    └── surah/
        └── surah-ya-sin.mp3   ← ملف التلاوة
```

مشغّل الصوت في `index.html` يقرأ `assets/audio/quran/metadata.json` عند تحميل الصفحة،
ثم يأخذ **أول عنصر** من نوع `"type": "quran"` ويعرض بياناته ويشغّل ملفه.
لا حاجة لتعديل `index.html` عند أي من العمليات التالية.

## حقول عنصر الصوت

| الحقل | المعنى | مطلوب |
|---|---|---|
| `id` | معرّف فريد | نعم |
| `type` | يجب أن يكون `quran` ليعتمده المشغّل | نعم |
| `title` | عنوان السورة الظاهر في المشغّل | نعم |
| `shortTitle` | اسم مختصر يُستخدم في النص البديل لصورة القارئ | لا |
| `reader` | اسم القارئ (يُعرض بعد عبارة «بصوت القارئ») | نعم |
| `info` | السطر الصغير (مكية · عدد الآيات …) | لا |
| `src` | مسار ملف الصوت **نسبةً إلى مكان index.html** | نعم |
| `format` | صيغة الملف (للتوثيق) | لا |
| `duration` | المدة للتوثيق، والمشغّل يحسب المدة الفعلية تلقائيًا | لا |

## تغيير اسم القارئ أو عنوان السورة
عدّل `reader` أو `title` في `quran/metadata.json` فقط، ثم أعد تحميل الصفحة (Ctrl+F5).

## استبدال ملف الصوت
1. ضع الملف الجديد في `quran/surah/`.
2. غيّر `src` ليشير إلى اسمه. أو احتفظ باسم الملف القديم نفسه وانسخ فوقه.

## إضافة ملف صوت جديد
1. انسخ الملف إلى `quran/surah/` (مثال: `surah-ar-rahman.mp3`).
2. أضف عنصرًا جديدًا داخل مصفوفة `audio` في `metadata.json`:

```json
{
  "id": "quran-rahman",
  "type": "quran",
  "title": "سُورَةُ الرَّحْمَٰن",
  "reader": "اسم القارئ",
  "src": "assets/audio/quran/surah/surah-ar-rahman.mp3",
  "format": "mp3"
}
```

**ملاحظة مهمة:** المشغّل الحالي يعرض سورة واحدة، وهي أول عنصر `quran` في القائمة.
العناصر الإضافية تُحفظ في الملف وتجهّز للمستقبل، لكنها لن تظهر في الصفحة قبل إضافة
قائمة اختيار سور إلى التصميم، وهذا لم يُنفَّذ حتى لا يتغير التصميم.
كذلك نص السورة المعروض أسفل المشغّل (سورة يس) مكتوب في `index.html` وليس هنا.

## نقل مجلد الصوت
انقل `assets/audio/` كاملًا مع الحفاظ على بنيته. إذا غيّرت موقعه، حدّث قيم `src` في
`metadata.json`، وحدّث سمة `data-metadata` على وسم `<audio id="audio-player">` في `index.html`
(وهذا هو التعديل الوحيد المطلوب في HTML لنقل المجلد).

## ملاحظات
- يجب تشغيل الموقع عبر خادم (مثل `http://127.0.0.1:3000`) ليقرأ المتصفح `metadata.json`.
  عند فتح الصفحة مباشرة كملف (`file://`) يمنع المتصفح قراءة JSON، فيستخدم المشغّل
  مسارًا احتياطيًا هو `assets/audio/quran/surah/surah-ya-sin.mp3`.
- الصيغة الموصى بها: MP3 (الحالي 96kbps ستيريو، ~15 م.ب، مدة 20:38).
- ابقِ أسماء الملفات بحروف لاتينية بلا مسافات.


## التثبيت كتطبيق (PWA)

أُضيف ملف manifest وأيقونات التطبيق وService Worker لتوفير التثبيت وفتح الموقع بواجهة مستقلة، مع تخزين ملفات الواجهة والبيانات الأساسية للاستخدام دون اتصال. لا يُحمّل ملف تلاوة سورة يس الكبير تلقائيًا عند التثبيت لتجنب استهلاك بيانات الزائر؛ يحتاج الصوت إلى اتصال أول مرة ما لم يكن قد تم تحميله مسبقًا.

**مهم عند النشر:** يجب رفع `manifest.webmanifest` و`service-worker.js` ومجلد `assets/icons/` بجانب `index.html` مع الحفاظ على المسارات، واستضافة الموقع عبر HTTPS (أو localhost أثناء التطوير). على iPhone تتم الإضافة من Safari عبر «مشاركة» ثم «إضافة إلى الشاشة الرئيسية».
